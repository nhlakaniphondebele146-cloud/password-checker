# JavaScript Password Evaluator

A security-focused script built using JavaScript that analyzes password entropy and structural complexity to flag insecure credentials 

## Features 
Entropy Calculation: Measures password strength based on character variation.
Complexity Validation: Checks for uppercase letters, lowercase letters, numbers, and special characters.
Immediate Feedback: Flags weak or compromised patterns to assist users in creating secure credentials.

## Installation & Setup
1. Clone the repository:
```bash
git clone https://github.com/nhlakaniphondebele146-cloud/password-checker
```
2. Navigate into the project directory:
```bash
cd password-checker
```

## Usage
Run the script locally to evaluate credentials:
```bash
node index.js
```
